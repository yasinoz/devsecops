# Lab Çözümü

Benim çözümüm:

- [lab/deployment.yaml](./lab/deployment.yaml)

Docker Desktop kümemde tüm kontroller uygulanabiliyor :)

Uygulama varsayılan olarak 80 portunu dinliyor, dolayısıyla tüm yetenekleri
düşürmek bazı kümelerde sorun olabilir. Benim güncellemem ayrıca farklı bir
porta, 5000'e geçiyor.

Kendi uygulamalarınızda da bu yaklaşımı izleyin; böylece toptan güvenlik
kontrolleri uygulayarak onları bozmadığınızdan emin olursunuz.
